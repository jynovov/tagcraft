怎么用
  1. 在 ComfyUI 里搭好工作流：Checkpoint → CLIPTextEncode ×2 → KSampler → VAE Decode → SaveImage
  2. 菜单 工作流 → 导出（API），把得到的 JSON 整段复制
  3. 粘到下面，先点「识别节点」确认正/负节点认对了，再点「测试连接」
  4. 回到「生成」页生成 tag，点「发送到 ComfyUI」——任务会自动进队列
Krea 2 的工作流也能直接复用：文本节点类名里只要带 TextEncode 就能被识别。 只有一个文本节点也可以，这时只写正向、不会覆盖别的内容；工作流只需要配一次，两个页面共用。
