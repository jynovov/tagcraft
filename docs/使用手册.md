# TagCraft · 中文 → Danbooru tag 本地小工具

给 ComfyUI + chenkinNoob-xl / NoobAI 系动漫模型用的**中文自然语言 → 英文 tag** 工具。
用你自己的大模型 API 把中文长描述转成规范 tag，再拿本地词表**逐条校验**，标红的说明模型编了词或不规范，一键换成候选。

```
中文长描述 ──► 大模型（你的 Key）──► 结构化 tag ──► 本地词表校验 ──► 复制进 ComfyUI
                                       │
                                 中文搜词 / 加权重 / 拖拽排序
```

## 一、启动与停止

**双击 `TagCraft.exe`**（带刻晴图标的那个）即可 —— 启动器自己找 Python、**后台无窗口运行**，然后自动打开浏览器。

| 方式 | 说明 |
|---|---|
| 双击 `TagCraft.exe` | **推荐**，无黑框、图标来自 exe 自身资源 |
| 双击桌面的 exe | 启动器自动定位项目，桌面不需要任何其他文件 |
| `start.bat` | 命令行兜底方式（会有黑框，功能一样） |
| 命令行 | ```cd tagcraft``` 然后 ```python server.py``` |

**停止服务**：点界面左侧栏的「退出」按钮（也可在任务管理器结束 `python.exe`）。
因为是无窗口运行，看不到黑框是正常的 —— **能打开网页就说明在运行**。

常用参数（命令行方式）：

```bat
python server.py --port 9000        :: 换端口
python server.py --no-browser       :: 不自动开浏览器
python server.py --no-update        :: 启动时不联网更新词表（纯离线用）
```

**前置条件只有两个**：Python 3.10+（不含任何第三方库，纯标准库）、一个能用的 OpenAI 兼容大模型 API Key。

- 启动器查找记录写在 `%LOCALAPPDATA%\TagCraft\launcher.log`
- 服务运行日志写在 `data\tagcraft.log`（无窗口运行，出问题看这个）

### 界面结构（左侧栏三个页面）

| 图标 | 页面 | 内容 |
|---|---|---|
| 生成 | `index.html` | 中文输入、查词、质量词/正向/未识别/负向四组结果、三路输出 |
| 历史 | `history.html` | 最近 30 条记录，可载入生成页 / 复制正向 / 删除 / 清空 |
| 设置 | `settings.html` | 大模型接口与 Key、温度、tag 上限、系统提示词、词表更新 |
| 退出 | — | 关闭本地服务 |

设置与历史都独立成页，不再堆在主界面上。

### 关于图标与桌面快捷方式

**桌面上只放一个 `TagCraft.exe`**。启动器**直接找 Python 启动 `server.py`**（不经 shell、不经 .bat，所以既没有安全警告弹窗，也没有黑框），找项目目录的顺序：
① exe 同目录 → ② 同目录 `launcher.ini`（可选覆盖）→ ③ 默认项目路径 → ④ 在「文档」下三层内搜索 `tagcraft` 文件夹。
所以把 exe 复制到桌面、任务栏、U 盘都能用；**只有移动了项目目录**才需要重编译或补一个 `launcher.ini`。

Python 是按候选逐个**实测**（跑一次 `import sys` 看退出码）挑出来的，PATH 里那种商店别名（退出码 9009）会自动跳过。

| 文件 | 说明 |
|---|---|
| `assets/tagcraft.ico` | 多尺寸图标：16/20/24/32/40/48/64/128 用标准 BMP 条目，256 用 PNG |
| `assets/source_keqing_user.png` | 图标素材原图（只取面部） |
| `make_icon_from_image.py` | 图标生成脚本：裁脸 → 提对比度/锐化 → 圆形取景 → 输出 PNG + ICO |
| `ico_util.py` | 手写 ICO 容器的工具函数 |
| `TagCraft.exe` | 用 `launcher.cs` 编译的启动器，图标写在 exe 的 PE 资源里 |

> ⚠️ **不要**用 Pillow 的 `img.save("x.ico", sizes=[...])` 生成图标——它会把所有尺寸都写成 PNG 格式，
> 资源管理器加载 16/32 小图标时会失败并显示成白纸。必须用 `ico_util.write_ico()`（小尺寸用 BMP 条目）。

重新生成图标（换图只需改 `make_icon_from_image.py` 里的 `SRC` 和 `CROP` 两个常量）：

```bat
python make_icon_from_image.py
```

重新编译启动器（为了换图标或改查找逻辑）：

```bat
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe ^
    /nologo /target:winexe /out:TagCraft.exe ^
    /win32icon:assets\tagcraft.ico /r:System.Windows.Forms.dll launcher.cs
```

**素材来源**：图标用的是你提供的刻晴同人图（只裁取面部）。刻晴是米哈游《原神》的角色，
请仅作个人本地使用，不要分发或商用。

如果换了图标后桌面还显示旧图：在桌面按 `F5`，或运行 `ie4uinit.exe -show` 刷新图标缓存。

## 二、界面怎么用

### 生成页（主界面）

| 区域 | 做什么 |
|---|---|
| 描述画面 | 写你想画的画面，可以很长（叙事、对话都没关系）。右上「上限」控制 tag 数量，建议 30–50 |
| 查词 | 输入中文或英文片段搜词表（如 `马尾`、`umbrella`），点 `+正` / `+负` 加进结果 |
| 结果 · 质量词 | `masterpiece / best_quality` 这类模型美学词**单独一组**，不混在正向 tag 里 |
| 结果 · 正向 tag | 点一下循环权重（1.0→1.1→1.2→1.3→1.5）、拖动排序、`×` 删除 |
| 结果 · 未识别 | 只显示**一个个小红框**（词表里查不到的）。点小红框弹候选，选一个替换或直接删掉 |
| 结果 · 负向 tag | 同上操作 |
| 输出 | 质量词 / 正向 / 负向**三个独立文本框**；可只复制质量词，也可「复制完整正向」把质量词+主体拼在一起；勾选权重语法输出 `(tag:1.2)` |

结果区右上三个按钮：**排序**（按「质量→角色作品→人数构图→外貌→表情动作→服装→场景→光照→镜头风格」重排）、**去重**、**校验**（重新按词表核对一遍）。

### 设置页（左侧栏「设置」）

大模型接口地址 / 模型名 / API Key / 温度、tag 上限、**系统提示词**（可改可恢复默认）、词表源选择与更新、连通性测试（「测试连接」）。

### 历史页（左侧栏「历史」）

最近 30 条记录，每条可以：**载入生成页**（把中文和 tag 一起带回去）、复制正向、删除；右上角可清空全部。

## 三、大模型怎么配

两种方式，任选：

**方式 A：在「设置」页填**（最快）
左侧栏点「设置」→ 填接口地址、模型名、Key → 保存（可点「测试连接」验证）。
Key 只存在你本机浏览器 localStorage 与本次请求里，不会上传到任何第三方。

**方式 B：`config.json`**（推荐，浏览器里不留 Key）
把 `config.example.json` 复制成 `config.json`，填好：

```json
{
  "api_base": "https://api.deepseek.com/v1/chat/completions",
  "api_key": "sk-你的key",
  "model": "deepseek-chat",
  "timeout": 120,
  "proxy": "",
  "port": 8848
}
```

也支持环境变量：`TAGCRAFT_API_KEY` / `TAGCRAFT_API_BASE` / `TAGCRAFT_MODEL` / `TAGCRAFT_PROXY`。

**常见接口地址**

| 服务 | api_base | model 示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `Qwen/Qwen2.5-7B-Instruct` |
| 阿里 DashScope | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-plus` |
| 本地 Ollama | `http://127.0.0.1:11434/v1/chat/completions` | `qwen2.5:7b` |

只要对方兼容 OpenAI 的 `/chat/completions` 协议就能用。走代理时把 `proxy` 填成 `http://127.0.0.1:7890` 这种形式。

## 四、词表（本地校验的关键）

工具内置两个词表源，下拉框可切换（首次启动自动下载默认源）：

| 源 | 条数 | 内容 | 大小 | 适合 |
|---|---|---|---|---|
| **ffdkj 中英对照表**（默认） | 33.1 万（≥10 张图） | 英文 tag、中文名、分类、出现次数 | 约 14 MB | **校验更准**（阈值低，不容易把好 tag 误判为"不存在"），MIT 许可 |
| GuWuW/danbooru-dict | 12.5 万（≥50 张图） | 上述四项 **+ 别名** | 约 5.4 MB | 下载快（走 jsDelivr CDN）、带别名 |

**两个源会自动互补**：无论用哪个做主表，工具都会把另一份里的**别名合并**进来（默认方案下能合并到 2.7 万条别名），所以中文搜索、别名搜索都能用。

**质量词白名单（重要）**：`masterpiece`、`best_quality`、`worst_quality`、`very_aesthetic`、`score_9` 这些**不是 Danbooru tag**，而是动漫 SDXL 模型（Pony / NoobAI / Illustrious 系）的美学词。工具内置白名单，会把它们标成「质量词（模型用）」**放行**，不会让你误删模型最需要的词。白名单在 `server.py` 的 `QUALITY_TAGS` 里，可以自己加。

**关于"词表里查不到"的正确理解**：查不到只代表**这个词表里没有**，不代表模型一定不认。常见三种情况：
1. 它其实是**别名**（比如 `flowers` 的规范写法是 `flower`，`holding_object` 是 `holding`）→ 点候选里的规范写法更稳
2. 它是**冷门 tag**（词表有阈值，太冷的没收录）→ 出图试试，能用就留着
3. 模型**真的编了一个词**（`rainy_night_alone` 这种）→ 删掉或换候选

第 1、2 种属于误报，第 3 种才是这个功能真正要抓的。常见别名对照表见 `../CKXL-中文提示词模板.md` 的第四节。

## 五、接口（想二次开发 / 接进 ComfyUI 的话）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 词表状态、当前模型配置、系统提示词、可用词表源 |
| GET | `/api/dict/search?q=中文或英文&limit=40&category=all` | 查词（category: 0 常规/1 画师/3 作品/4 角色/5 质量元数据） |
| GET | `/api/dict/suggest?tag=xxx` | 给一个不存在的 tag 找候选 |
| POST | `/api/dict/validate` | body `{"tags":[...]}` → 返回合法/非法 + 候选 |
| POST | `/api/dict/update` | body `{"source":"ffdkj"}` → 下载并重建词表 |
| POST | `/api/generate` | body `{"text":"中文描述","max_tags":40,"temperature":0.6,"api":{"api_base":"...","api_key":"...","model":"..."}}` |

`/api/generate` 返回的每一批 tag 都已经过词表校验，字段分得很清楚：`positive` / `positive_unknown` / `negative` / `negative_unknown` / `notes`。

## 六、常见问题

**Q：弹出「打开文件 - 安全警告 / 无法验证发布者。你确定要运行此软件吗？」**

这是 Windows 对**通过 shell 打开批处理文件**的发布者校验，和病毒无关。已经从两个层面解决：

1. **`TagCraft.exe` 不再打开 `start.bat`**——它自己查找 Python 并直接启动 `server.py`，且用 `UseShellExecute=false`（**不经过 shell**）。
   所以用 exe 双击启动**不会**再出现这个弹窗，进程链里只有 `python`，没有 `cmd`。
2. 启动器还会顺手清掉文件上的「来自网络」标记（Zone.Identifier）。

如果你仍然看到弹窗，那是你系统上的安全软件（火绒 / 360 / Defender 应用控制）在拦未签名程序，把 `TagCraft.exe` 加白名单即可。

**只有直接双击 `start.bat` 时**才可能看到这个弹窗（shell 打开 .bat 才会校验）。两个办法：
- 改用 `TagCraft.exe`；
- 或右键 `start.bat` → 属性 → 底部勾选「解除锁定」→ 确定（等价命令：`Unblock-File .\start.bat`）。

**Q：双击 start.bat 闪一下就没了 / 提示找不到 Python**
装 Python 3.10+（[python.org](https://www.python.org/downloads/)，安装时勾选 *Add Python to PATH*）。ComfyUI 便携版的 `python_embeded\python.exe` 也能用：
`python_embeded\python.exe tagcraft\server.py`

**Q：GitHub 下载词表很慢或失败**
换成另一个源重试；或先用内置种子词表（不影响大模型生成，只影响校验覆盖）。

**Q：提示"还没有填 API Key"**
去「设置」页填，或建 `config.json`。

**Q：生成的 tag 里有红色项**
那就是校验起了作用，点候选替换或直接删掉。

**Q：报 `接口返回 401`**
Key 错了或没余额。报 `model not found` 就是模型名写错了。

**Q：词表更新到一半卡住**
下载是同步的，点完等它跑完即可（进度写进 `data\tagcraft.log`）。断了就再点一次，不会损坏数据。

**Q：双击后没有黑框，怎么知道它在运行？怎么关掉？**
现在是无窗口后台运行（就是这样设计的）。能打开 http://127.0.0.1:8848/ 就是在运行；要关掉就点左侧栏最下面的「退出」（或在任务管理器结束 `python.exe`）。

**Q：能不能不联网用？**
可以。`python server.py --no-update` 启动，用内置种子词表 + 手动中文搜词，完全离线；但大模型那一步需要 API（除非接本地 Ollama，那也能全离线）。

**Q：这段提示词能改吗？**
能。界面上「查看/修改系统提示词」随便改——**CKXL 这类融合模型推荐的质量词、负向词请按它的模型卡改**（提示词模板文档里也写了）。

## 八、想继续改造的几个方向（都不难）

1. **做成 ComfyUI 自定义节点**：`server.py` 的 `/api/generate` 已经是个现成 HTTP 接口，节点里 requests 调它、把返回值接到 `CLIPTextEncode` 即可
2. **直接调用 ComfyUI 的 `/prompt` 接口出图**：生成 tag 后一键排队，做"中文→出图"闭环
3. **换更强的词表**：把任意 `name,category,post_count,aliases,cn` 格式的 CSV 放到 `data/`，改 `SOURCES` 里的地址即可（解析器已支持表头识别、单/双引号、列序自适应）
4. **加 ComfyUI 工作流模板**：把常用参数（分辨率、采样器、LoRA）存成预设，输出提示词时一起给出
